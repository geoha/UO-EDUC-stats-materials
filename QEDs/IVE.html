Using R for Quasi-Experimental Designs

Part 8 Instrumental Variable Estimation

This is an introduction to instrument variable estimation (IVE), following Chapter 10 of Murnane and Willett (2011).

8.1 Objectives

  1. Calculate the local average treatement effect (LATE) using the method of moments
  2. Estimate LATE using two-stage least squares
    1. Noticing the covariance among residuals in the two stages
  3. Include covariates in the two-stage least squares model
  4. Use multiple instruments and model a system of equations to estimate LATE

We’ll use these packages:

  • sem (Fox et al., 2020),
  • AER (Kleiber & Zeileis, 2020), and
  • systemfit(Henningsen & Hamann, 2019).

We had used the sem package in a previous lesson for fitting two-stage least squares models. The AER package is another one that provides the same functionality plus the R2 estimates of the model. The systemfit package is good for complex IV estimation models. In this lesson, we use it to fit the model presented in Table 10.8 (p. 249).

For help on these packages’ functions, we can use can use the question mark and the double colon between the package name and function name, for example ?AER::ivreg. To see the help files for a package, we can use help(package = "AER").

Because the covariance matrix includes the variances and covariances, we can calculate the estimated causal effect of college on voter registration.

deecov <- cov(dee[, my10.2varbs])
round(deecov, 4)
##          register college distance
## register   0.2208  0.0438  -0.1369
## college    0.0438  0.2478  -0.4825
## distance  -0.1369 -0.4825  75.7298

Here’s the method-of-moments IVE estimate, which is the same as the Wald estimator. From our covariance matrix, we’re using the cell that contains the covariance between the the outcome variable (register) and instrument (distance), \(\sigma_{YI}\), and the covariance between the question predictor (college) and the instrument, \(\sigma_{XI}\), then finding that ratio:

\[\begin{eqnarray} \beta_1 = \frac{\sigma_{YI}}{\sigma_{XI}} = \frac{-0.1369}{-0.4825} = 0.2837 \tag{8.1} \end{eqnarray}\]

sigma_YI <- deecov[1,3]
sigma_XI <- deecov[2,3]
IVE_estimate <- sigma_YI/sigma_XI
rbind(sigma_YI, sigma_XI, IVE_estimate)
##                    [,1]
## sigma_YI     -0.1368732
## sigma_XI     -0.4824722
## IVE_estimate  0.2836913

Murnane and Willett present this same ratio in Figure 10.4 (p. 236). Putting this into words, The denominator is the carved out portion of the question predictor that we believe is exogenous; the numerator is the part of that exogenous variance that is shared with the outcome variable. This method-of-moments represents the logic underlying IV estimation.

8.4 Two-stage Least Squares

8.4.1 First stage

First, let’s look at the first stage, with ordinary least squares (OLS), which is what is reported in Table 10.3 (p. 228). As we did with the method-of-moments equation, we can use generic symbols, with \(X\) for our question predictor of interest and \(I\) for the instrument.49

\[\begin{equation} X_i = \alpha_0 + \alpha_1I_i + \delta_i \tag{8.2} \end{equation}\]

In our example, this first-stage equation is \[\text{college}_i = \alpha_0 + \alpha_1\text{distance}_i + \delta_i \text{ .}\]

s1 <- lm(college ~ distance, data=dee)
summary(s1)

Notice that the F-statistic (115.86) exceeds the \(F \geq 10\) rule of thumb that many people use for examining whether an IV is strong enough to use.

8.4.2 Second stage

Here’s the second stage, with OLS.

\[\begin{equation} Y_i = \beta_0 + \beta_1\widehat{X}_i + \epsilon_i \tag{8.3} \end{equation}\]

In the code, we’re first estimating the predicted college attendance, based on the first stage’s model.50 The estimate is correct but the standard error is not yet adjusted for the Stage 1 portion, so the model results are not what we would provide in our report.

dee$pred_coll <- fitted(s1) 
s2 <- lm(register ~ pred_coll, data = dee)
summary(s2)
## 
## Call:
## lm(formula = register ~ pred_coll, data = dee)
## 
## Residuals:
##     Min      1Q  Median      3Q     Max 
## -0.6885 -0.6613  0.3170  0.3296  0.3748 
## 
## Coefficients:
##             Estimate Std. Error t value Pr(>|t|)    
## (Intercept)   0.5157     0.0485  10.632   <2e-16 ***
## pred_coll     0.2837     0.0882   3.216   0.0013 ** 
## ---
## Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
## 
## Residual standard error: 0.4697 on 9225 degrees of freedom
## Multiple R-squared:  0.00112,    Adjusted R-squared:  0.001012 
## F-statistic: 10.35 on 1 and 9225 DF,  p-value: 0.001302

Notice that the estimate is the same as it was in our method-of-moments approach. This is because we have no covariates. We can also think of the second-stage equation as including the first-stage equation. To expand a little upon the footnote that Murnane and Willett provided (p. 230), we can replace \(\hat{X}_i\) in \({Y_i = \beta_0 + \beta_1\hat{X}_i + \epsilon_i}\) with what it is in the first stage, \(\hat{X}_i = \alpha_0 + \alpha_1I_i\). Plugging it in, we have \({Y_i = \beta_0 + \beta_1(\alpha_0 + \alpha_1I_i) + \epsilon_i}\), which we can also write as \({Y_i = \beta_0 + \beta_1\alpha_0 + \beta_1\alpha_1I_i + \epsilon_i}\).

We can plug this into the \(Y_i\) part of the covariance in the numerator of the method-of-moments equation \(\big(\beta_1 = \frac{\sigma_{YI}}{\sigma_{XI}}\big)\): \[ \sigma_{YI} = {\text{Cov}\Big((\beta_0 + \beta_1\alpha_0 + \beta_1\alpha_1I_i + \epsilon_i}),I_i\Big) \] We can remove the parts of this covariance that include constants (i.e., the parameter estimates) and residuals.51 \[ \begin{eqnarray} {\text{Cov}\Big((\beta_0 + \beta_1\alpha_0 + \beta_1\alpha_1I_i + \epsilon_i}),I_i\Big) &=& \text{Cov}(\beta_0,I_i) + \text{Cov}(\beta_1\alpha_0,I_i) + \text{Cov}(\beta_1\alpha_1I_i,I_i) + \text{Cov}(\epsilon_i,I_I)\\[5pt] &=& 0 + 0 + \text{Cov}(\beta_1\alpha_1I_i,I_i) + 0 \end{eqnarray} \] Pulling the constants out, we have \(\sigma_{YI} = \beta_1\alpha_1\text{Cov}(I_i,I_i) \text{ .}\) And, because the covariance of a variable with itself is its variance, we have \(\sigma_{YI} = \beta_1\alpha_1\sigma_I^2 \text{ ,}\) which we can re-arrange as

\[\begin{eqnarray} \frac{\sigma_{YI}}{\alpha_1\sigma_I^2} &=& \beta_1 \text{ , and then}\\[5pt] \beta_1 &=& \frac{\sigma_{YI}}{\sigma_I^2} \times \frac{1}{\alpha_1} \end{eqnarray}\]

Because the slope in a simple regression is \(\frac{\sigma_{xy}}{\sigma_x^2}\), we can replace \(\alpha_1\) with \(\frac{\sigma_{XI}}{\sigma_I^2}\) and we end up with the same ratio we use in the method of moments.

\[\begin{eqnarray} \beta_1 &=& \frac{\sigma_{YI}}{\sigma_I^2} \times \frac{1}{\frac{\sigma_{XI}}{\sigma_I^2}} \\[5pt] &=& \frac{\sigma_{YI}}{\sigma_{XI}} \end{eqnarray}\]

All that is to say that the \(\beta_1\) in the second-stage equation is the same as the \(\beta_1\) in the ratio that we had earlier used in the method-of-moments LATE estimation, Equation (8.1). Again, this ratio represents the underlying logic of IVE, and is nicely presented in Figure 10.4 of Murnane and Willett.

8.4.3 Obtaining the correct standard errors

The standard error of our parameter of interest, \(\beta_1\), in regular OLS estimation of the second stage, in Equation (8.3), is not correct. We can calculate this by hand using the following three steps:

We first plug into the Stage 2 equation the observed values on the question predictor, \(X_i\), and save the residuals, which we’ll call \(\eta_i\). We calculate its standard deviation, which we’ll call \(\sigma_{\eta}\). We’ll use this in the equation in the third step.

preds <- predict(s2, 
                 newdata = data.frame(register  = dee$register, 
                                      pred_coll = dee$college))
eta_i <- dee$register - preds
(sd_eta <- sd(eta_i))
## [1] 0.4646491

Second, we calculate the standard deviation of the predicted values in the Stage 1 equation. Let’s call this \(\sigma_{\hat{X}}\).

(sd_pred_coll <- sd(s1$fitted.values))
## [1] 0.05544201

Third, we use the following equation to calculate the correct two-stage-least-squares standard error of our parameter estimate in Equation (8.3):

\[\begin{equation} SE_{\beta_12SLS} = \frac{\sigma_{\eta}}{\sqrt{n} \times \sigma_{\hat{X}}} \tag{8.4} \end{equation}\]

n_dee <- sum(!is.na(eta_i))
(se_2SLS <- sd_eta/(sqrt(n_dee)*sd_pred_coll))
## [1] 0.08724808

With this, our test statistic is now \(\frac{0.284}{0.087} = 3.252\text{.}\)

8.4.5 Noticing the covariance between errors

Table 10.4 in Murnane and Willett includes the correlation in errors between the first stage (with OLS) and the second stage (from the 2SLS model):

cor(s1$residuals, ts$residuals)
## [1] -0.1150957
cor.test(s1$residuals, ts$residuals)
## 
##  Pearson's product-moment correlation
## 
## data:  s1$residuals and ts$residuals
## t = -11.129, df = 9225, p-value < 2.2e-16
## alternative hypothesis: true correlation is not equal to 0
## 95 percent confidence interval:
##  -0.13518279 -0.09491396
## sample estimates:
##        cor 
## -0.1150957

The correlation is statistically significant (which is not surprising given that the sample is pretty big). We wouldn’t normally include this in our analysis but it shows that the covariance between the residuals is not likely a random fluke.

This covariance between residuals represents the portion of the covariance between the question predictor and the outcome that we are not able to capture with our instrument. In other words, this is the non-carved-out covariance that would otherwise bias our estimate if we had simply regressed Y on X. In using an instrumental variable that is exogenous, we are able to set this potentially endogenous covariance aside.

8.5 Two-Stage Least Squares with Covariates

There are two reasons to include covariates.

  • First, as is generally case in causal models, if the covariates explain what would otherwise be residual variance in the outcome variable, we increase our statistical power in detecting an effect in the parameter of interest \(\text{(}\beta_1 \text{,}\) which is the slope for college in our example).
  • The second reason is more specific to IVE. We might anticipate critiques from reviewers about the credibility of our exclusion restriction—that is, that the instrumental variable is related to the outcome variable only through our question predictor. The exclusion-restriction assumption in this study is that any relationship between distance (distance between one’s high school and the nearest college) and registration (whether they registered to vote) is fully explained by whether the person went to college or not. If there are reasons to believe that relationship exists outside of this mechanism, our estimated effect of college can be biased. However, if we have covariates that capture this other mechanism, we can condition on these covariates and provide a stronger case that we have met this assumption. We might then think of our instrument as a conditional instrumental variable (Morgan & Winship, 2015).

8.6.1 System of equations

The system of equations also provides estimates of these first four equations along with the fifth equation. Let’s use the systemfit package for this.

First we define each equation in the systems of equations:

library(systemfit)
eq1 <- college ~ distance + black + hispanic + otherrace + distance*(black + hispanic + otherrace)
eq2 <- college*black    ~ black    + distance*black
eq3 <- college*hispanic ~ hispanic + distance*hispanic
eq4 <- college*otherrace~ otherrace+ distance*otherrace
eq5 <- register ~ college + black + hispanic + otherrace + college*(black + hispanic + otherrace)

Now, we can use those specifications to fit the model. First, we define our instruments. Then, we create a list of the system of equations that we had just created. To fit the model, we use the systemfit() function; the first argument is the formula—our system of equations. For the method, we specify “2SLS.” We list the instruments that we had defined and, of course, the data. The output from summary() is pretty long because it presents all five equations, so we are asking in the last line for our last equation only.

inst <- ~ distance + distance*(black + hispanic + otherrace) # defining our instruments
system <- list(eq1 = eq1, eq2 = eq2, eq3 = eq3, eq4 = eq4, eq5 = eq5) #the list of equations
reg2sls <- systemfit(system, 
                     method = "2SLS", 
                     inst = inst, 
                     data = dee)
summary(reg2sls)$eq[[5]] # reporting only the last equation.
