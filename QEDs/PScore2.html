Using R for Quasi-Experimental Designs

Part 11 Propensity Score Analysis 2: Weighting

Inverse probability (or propensity) weighting (IPW) is probably the easiest propensity-score method to use. In this session, we continue with the data from the previous unit but this time we have split it into two data sets: one with all the covariates and another with only the outcome variables. This is good practice because we separate the decisions the researcher makes into two independent steps. The first step involves finding the best combination of covariates, deciding on a method of propensity-score estimation, and deciding which propensity-score adjustment method to use—weighting, stratification, or matching (we use weighting in this unit). In the second step, we estimate the causal effect.

We will assess imbalance and overlap in our covariates before and after applying the IPW adjustments. We will use some custom functions for this (which we will not elaborate on). For this first part, we will use the same method—logistic regression—for estimating the propensity scores. The outputs of the balance statistics and plots help us in evaluating how well the IPWs worked. After this, we will estimate the effect using the survey package (Lumley, 2021), which is valuable for correctly estimating the standard error. Finally, we will try out the twang package (Cefalu et al., 2021), which is one of many propensity-score packages that has functions for estimating propensity scores and applying weighting. With twang, we will not use logistic regression but instead will use a generalized boosted model, which is the default in twang’s function. We end by estimating the causal effect given these GBM inverse probability (IP) weights, again with the survey package.

11.2 Specify Custom Functions

Let’s create some custom functions. The first ones are for assessing imbalance due to selection bias. The next are for examining overlap and common support. I credit Peter Steiner with the original versions of these functions, which I have further modified. Any mistakes are due to my own modifications. We can also use functions from packages developed for propensity score analyses, such as twang (Cefalu et al., 2021), to achieve similar imbalance statistics and plots.

11.2.1 Imbalance functions

As we have done before, we will assess imbalance in the observed covariates in the levels of the treatment variable, catholic, by examining the standardized mean difference and variance ratio. Here are the three arguments in this function:

  • x is our baseline covariate,
  • grp is our grouping variable (catholic in our data), and
  • wt is the weight applied to the unit.

This version of our custom function has an additional component that our previous one did not, wt =. In this lesson, the weight is the IPW (the inverse-propensity weight). We can also use this function for stratum weights that use marginal mean weighting through stratification (MMWS). When examine balance before applying IPW or MMWS, we specify the weights of each observation as being the same. We’ve specified this as the default with wt = rep(1, length(x)). Within the function, we estimate the weighted mean and variance of the covariate.67

wselect.diff <- function(x, grp, wt = rep(1, length(x))) {
   if (is.factor(grp)) grp <- as.numeric(grp) - 1     # transform dichotomous factor into dummy
   if (is.factor(x)) x <- as.numeric(x) - 1           # transform dichotomous factor into dummy
   stat.wt <- function(xw) {                          # function computing weighted mean and variance
      out <- cov.wt(xw[, 1, drop = F], xw[, 2])
      c(mean.wt = out$center, var.wt = out$cov)
   }
   stat <- unlist(by(cbind(x, wt), grp, stat.wt))     # weighted mean and variance (vector)
   m <- stat[seq(1, 4, by = 2)]                       # extract means
   v <- stat[seq(2, 4, by = 2)]                       # extract variances
   B <- (m[2] - m[1]) / sqrt(sum(v) / 2)              # standardized difference in means
   R <- v[2] / v[1]                                   # variance ratio
   rslt <- summary(lm(x ~ grp, weights = wt))         # run regression test
   res <- c(rslt$coef[2, c(1:2, 4)], B, R)
   names(res) <- c("Mean.Diff", "Std.Error", "p-value", "Std.Mean.Diff", "Var.Ratio")
   res
}

11.2.2 Overlap functions

We can use this function to plot the overlap between the treatment and control group on a covariate.

  • x is our covariate, as a numeric vector
  • z is our treatment indicator (dummy coded as 0 and 1)
  • title is the label to use for the plot title (optional)
  • xlab is the label of the X axis (optional)
  • bin is the number of bins for the histogram, defaulting to 20
overlap <- function(x, z, title = NULL, xlab = NULL, bin = 20, Ccol="papayawhip", Tcol="olivedrab4")
{
   r1 <- range(x)
   if (!is.numeric(z)) z <- as.numeric(z) - 1
   c.dat <- hist(x[z == 0], breaks = seq(r1[1], r1[2], length = bin), plot = F)  # histogram data for control (untreated) group
   t.dat <- hist(x[z == 1], breaks = seq(r1[1], r1[2], length = bin), plot = F)  # histogram data for treated group
   t.dat$counts <- -t.dat$counts
   plot(c.dat, axes = F, ylim = c(min(t.dat$counts), max(c.dat$counts)),
        main = NULL, xlab = xlab, col=Ccol)
   title(main = title, adj = 0, cex = .8)
   plot(t.dat, add = T, density = 30, col = Tcol)
   axis(side = 1)
   ax.loc <- axis(2, labels = F)
   axis(2, at = ax.loc, labels = abs(ax.loc))
   y <- par('usr')[3:4]
   text(rep(max(x), 2), c(y[2] - diff(y)*.05, y[1] + diff(y)*.05), 
        c('Untreated', 'Treated'),adj = 1, xpd = T)
}

Next is our function for generating overlap plots with kernel density estimates. These plots will also illustrate mean differences, with vertical lines superimposed on the plots. This plots kernel-density estimates for each group on the variable, the grouping variable, and with the weights.

dnsty <- function(x, grp, wt = rep(1, length(x)), main = NULL, 
                  lwd = 1, col.vec = c('black', 'blue'), legtitle = NULL, ...) 
{
   lev  <- levels(grp)
   cmplt <- na.omit(data.frame(x, grp, wt))
   x    <- cmplt$x
   grp  <- cmplt$grp
   wt   <- cmplt$wt
   dens <- list()
   x.m  <- rep(NA, length(table(grp)))
   bw   <- density(x, weights = wt / sum(wt))$bw
   for (i in 1:length(table(grp))) {
      grp.ind <- grp == lev[i]
      dens[[i]] <- if (is.null(wt)) density(x[grp == lev[i]], ...) else
                  density(x[grp.ind], na.rm = T, weights = wt[grp.ind] / sum(wt[grp.ind]), bw = bw, ...)
      x.m[i] <- weighted.mean(x[grp.ind], w = wt[grp.ind]) 
   }
   plot(dens[[1]], type = 'n', main = main, xlab = '', ylab = '', yaxt = 'n',
        ylim = c(0, max(c(dens[[1]]$y, dens[[2]]$y))), 
        xlim = range(c(dens[[1]]$x, dens[[2]]$x)), bty = 'l')

   for (i in 1:length(table(grp))) {
      grp.ind <- grp == lev[i]
      ind <- dens[[i]]$x - x.m[i]
      lines(dens[[i]], col = col.vec[i], lwd = lwd, lty = 3 - i, xpd = T)
      lines(rep(x.m[i], 2), c(0, dens[[i]]$y[abs(ind) == min(abs(ind))][1]), col = col.vec[i], lwd = lwd, lty = 3)
   }
   legend('topright', levels(grp) , title=legtitle,
   lty=c(2,1), col=col.vec, bty='n', cex=.75)
}

We can use that dnsty() function to plot within for loops. If we do this several times, we might as well write a function that includes the for-loop. This one has several arguments, which feed into the dnsty() function plots. For this particular analysis, we’ll specify these arguments later on as this:

  • df will be our data frame, ca.
  • xnames will be the names of the variables we wish to compare between groups. For our covariates, we have created this object, covnames.
  • grp will be catholic.
  • wt will not be specified if we are not using weights (i.e., for examining plots before we adjust the observations) and it will be the weights in the data set that we calculate when we plot these after the adjustment.
  • subtitle is available if we want to add to the plot title, for example "(before the IPW adjustment)".
  • legtitle is there if want to specify the name of the treatment group variable, Catholic.
dnsty_plotter <- function(df , xnames, grp, wt = rep(1, nrow(df)), subtitle = NULL, legtitle = NULL){
   if (length(xnames) >1)  par(mfrow = c(2,2))
  for (i in 1:length(xnames)){
   nam <- xnames[i]
   x <- df[, nam]
   if (!is.numeric(x)) x <- as.numeric(x)
   dnsty(x, grp, wt = wt, main = paste(nam,"\n", subtitle), legtitle = legtitle)
 }
  par(mfrow = c(1,1))
}

11.5 Calculate the Weights

Let’s fit an initial propensity-score model and save each ith person’s fitted estimate as the propensity score, which is often symbolized as \(\hat{e}(x_i)\), or more succinctly as \(e(x)\), and which we’ll save in the code as ps.

We can use our object that contains the names of our covariates, covnames to create the equation for our propensity score model. We can use the as.formula() function with the paste() function. Notice that we have a second paste function inside the first, this paste(covnames, collapse = ' + ') code takes the elements from our covnames object and puts a + between each, which is what is needed in our formula. Notice that our equation does not include polynomials unless we create these up front, as we did with the inc8Sq covariate (from inc8Sq <- ca$inc8^2).

(ps_mdl1 <- as.formula(paste('catholic', '~', paste(covnames, collapse = ' + '))))
## catholic ~ inc8 + inc8Sq + math8 + mathfam + fhowfarN + mhowfarN + 
##     fight8N + nohw8N + disrupt8N + riskdrop8

Let’s use our formula in our propensity-score model

The weights for the ATE are calculated as the inverse of the observation’s propensity to be in the group they are in. For the treatment group, the ATE weight is \(W_i = \frac{1}{\hat{e}(x_i)}\); for the control group, it is \(W_i = \frac{1}{1-\hat{e}(x_i)}\). In a single equation, we can use the treatment group status (\(Z_i = 1\) for the treatment and \(Z_i = 0\) for the control) as a switch:

\[\begin{equation} \text{ATE IPW} = \frac{Z_i}{\hat{e}(x_i)} + \frac{1-Z_i}{1-\hat{e}(x_i)} \tag{11.1} \end{equation}\]

For the ATT, the weights are 1 for the treatment group and the odds for the control group, \(\frac{\hat{e}(x_i)}{1-\hat{e}(x_i)}\). In a single equation,

\[\begin{equation} \text{ATT IPW} = {Z_i} + (1-Z_i)\frac{\hat{e}(x_i)}{1-\hat{e}(x_i)} \tag{11.2} \end{equation}\]

We can think about the counterfactual in the ATT to help us understand this weighting. We’re interested in the effects on the treated and we seek to know what their counterfactuals would be so we can estimate an unbiased group difference. A control-group person’s odds of being in the treatment group weights them as a counterfactual. In other words, a control-group person with a greater likelihood of selecting into the treatment group will be more heavily weighted in the estimation than will a control-group person who has very little interest in being treated.

In our data set, we need to use the numeric version of our treatment variable, catN:

ca$ipwt_ATE <- with(ca, catN / ps + (1 - catN) / (1 - ps)) 
ca$ipwt_ATT <- with(ca, catN + (1- catN) * ps / (1 - ps))

11.5.2 Specifying whether to estimate ATE or ATT

Early in our study, we will have decided whether the ATE or ATT is more appropriate for our research question. With the ATE, we are interested in the average causal effect after accounting for selection bias. With the ATT, we are interested in the effect of being in the treatment group in comparison to that counterfactual condition, which is best estimated by weighting counterparts in the control group based on their likelihood of being in the treatment.

We can use the code here to switch either the ATE or the ATT on, and then examine the balance and overlap. Try switching on another other and examining balance and overlap. Then, after we’re happy with our design part (our PS model), we can estimate the effect on our outcome.

ca$ipwt <- ca$ipwt_ATE

11.7.1 Estimating the correct standard error

We can estimate the standard errors using the survey() package (Lumley, 2021).70

The first thing we do is create an object that contains the design, using the svydesign() function. The first argument, ids = ~1 specifies what the primary sampling unit is. In our case, we use ~1 because this instructs the function to use each row in the data frame as the primary sampling unit. If we also had used a complex survey design, we might have identified a column in the data that identified the cluster—we’re not using that design in this example. The weights = ~ipwt argument specifies which variable in the data frame is the weights.

library(survey)
sdesign <- svydesign(ids = ~1, weights = ~ipwt, data = ca2)

fit <- svyglm(math12 ~ catholic, design = sdesign)

11.7.2 Use a doubly robust estimate

We have applied the inverse-propensity-score weighting approach to adjust our estimate and standard error of the causal effect. To provide an even stronger argument that our estimate has been adjusted based on these covariates, we can use what’s called a doubly robust (Bang & Robins, 2005) approach and further condition on any ornery covariates—those that remain somewhat imbalanced even after we have adjusted observations by their propensity scores.

If we flag any imbalance, such as by arbitrarily setting \(\leq .05\) standardized mean difference as the criterion for inclusion, we can determine which covariates, if any, to include in the doubly-robust model.

covs_need_robust <- imbal_adj[ abs(imbal_adj[,4]) > .05, ] #Just seeing which covariates to include
row.names(covs_need_robust)
## [1] "fight8N"   "disrupt8N"

With the ATE, there are two covariates we can include.71

If we want, we can automate this selection of covariates to include in the robust formula by pulling out the covariate names and using the as.formula() function.

covs_for_robust <- row.names(covs_need_robust)
(robust_formula <- as.formula(paste('math12', '~ catholic + ', paste(covs_for_robust, collapse = ' + ')))) 
## math12 ~ catholic + fight8N + disrupt8N

Again, we can use the survey package. We already specified the survey design,sdesign.

library(survey)
fit_rob <- svyglm(robust_formula, design = sdesign)
summary(fit_rob)

11.8.2 Estimating the propensity scores and getting the weights

With twang, we can use a formula similar to the one we created using the as.formula() function for the propensity score model using glm(); the difference is we need to specify the outcome variable as our numeric version of the variable, so we’ll use catN instead of catholic. In twang, the ps() function is available for estimating the propensity scores. The default method is generalized boosted modeling (GBM) instead of logistic regression. This procedure takes a minute to run because, compared to regular old logistic regression, GBM uses a more intensive iterative procedure.

library(twang)
# Creating a new formula, with catN instead of catholic as the treatment-group variable.
ps_mdl_4twang <- as.formula(paste('catN', '~', paste(covnames, collapse = ' + ')))

set.seed(10310210)
twang_ps <- ps(ps_mdl_4twang, 
               data = ca,
               estimand = "ATE",
               stop.method = "es.mean", # standardized effect size
               verbose = FALSE)         # To prevent the in-progress iterations from printing in the console

We have saved the outcome of the propensity-score model as an object. We can use twang’s bal.table() function on this to return the balance statistics of all of the covariates used in the model both before and after they were weighted by the inverse-probability weights.

bal.table(twang_ps)

We can examine plots of the standardized mean difference before and after weighting. This plot is nice because it displays the 0.10 benchmark for evaluating balance. Our remaining culprit here is riskdrop8.

 plot(twang_ps, "es")

We can save the GBM-estimated propensity scores to our data set—the one without the outcome variables in case we need to further assess how well the weighting balanced the covariates.

ca$ps_gbm <- twang_ps$ps$es.mean.ATE

To get the IP weights, we use the get.weights() function. We need these, of course, when we estimate the effects.

ca$ipw_gbm <- get.weights(twang_ps, stop.method = "es.mean")

We might wish to use our custom function, dnsty(), to examine whether common support after adjustment is as nice as it was with our logistic-regression approach to estimating propensity scores.

The GBM IP weights did improve common support over the unadjusted GBM propensity scores but not as well we saw before with the logistic-regression IP weights. We might use this evidence in our decision about whether to use logistic-regression over GBM.

However, we have still arrived at the same statistical conclusion in terms of the direction of the effect and statistical significance.
