Preparing and Analyzing Survey Data in R

Part 7 Introduction to the Analysis of Complex Survey Data

In a garden variety simple-random-sample design, we randomly sample units from a larger population and then estimate the mean, standard deviation, and confidence intervals to subsequently draw an inference about the larger population. This is the assumption underlying the example and explanations in the previous chapters. In this chapter we examine complex survey data. In survey designs with complex data, we need to make corrections to the standard error, which in turn affects the confidence intervals, which subsequently affects our inference about the statistic—such as the mean—in the population we seek to make claims about.

7.1 Packages

There are two packages that are handy for analyzing complex survey data: The survey package (Lumley, 2020) and the similarly named srvyr package (Freedman Ellis & Schneider, 2021), which works with the survey package to make the output easier to work with (because why would the survey package on its own make life easy?). Harkening back to a previous chapter, we need to first be sure we have these packages installed. We will also use the dplyr package (Wickham, François, et al., 2020) again, as this uses the same data-wrangling language that the srvyr package does.28

library(survey)
library(srvyr)
library(dplyr)

7.3 The three hypothetical complex designs

7.3.1 Pretending we have a cluster-sampled design

We will use this data set to practice analyzing the data in a cluster-sampled design. This would be the kind of analysis we would conduct if we had randomly sampled schools—that is, our clusters—from a broader population of schools (such as from a sampling frame that listed all of the schools in the country). In this design, our primary sampling unit is schools. Within each school, we have students, whom we had administered the survey to.30 This design is very convenient because it is easier to randomly sample schools from a list of schools, whereas it is virtually impossible to have a list of all of the individual students in the country. We pay a price for this convenience, though, because students who are nested within schools tend to live in similar neighborhoods, share the same values, have the same learning experiences, and so forth, so if we used a run-of-the-mill standard error (and confidence interval), we will be overly optimistic in how precise we are in estimating the population. When we correctly analyze these data, we pay a penalty because our standard error is corrected to be larger than it would be with a simple random sample.

7.3.2 Pretending we have a stratified design

After analyzing the cluster-sampling design data, we’ll erase our memories of that design and pretend we’re analyzing a stratified design. In this type of design, we have have conducted a simple random sample of students within strata. In this case, the students are our primary sampling unit. Let’s say we have a list of school districts—these are our strata. We then have a list of all the students in each district, which is our sampling frame. We randomly selected students from each district, then we estimate the mean of the population. This is a very powerful design if we believe that the strata explain a lot of variation in the variable (in the score, in this case). It helps us to have greater precision in our estimate of the population mean.31

7.3.3 Pretending we have a stratified cluster-sampled design

After monkeying around with a stratified design, we wipe our memories of how we had designed that study and pretend we had collected the data using schools as our primary sampling unit, similar to how we did with the cluster-sampled design, but this time we sample schools from within their districts. The districts are strata. So, we have students nested within schools, which were randomly selected, which in turn are nested within strata. This is a very practical and smart design to use. First, we have the convenience of sampling schools, which is far easier than randomly sampling students from lists. Second, we can reduce that penalty to the standard error of this clustering by also using a stratification variable—the districts. This allows us to make claims about the population of schools within these particular districts.

We will also pretend we have a simple random sample, as well, to compare these scenarios with each other in terms of the standard error and confidence intervals.

7.4 Cluster-sampled design

7.4.1 Preparing the data

In the example that Heeringa and colleagues provide, they did not use a finite population correction. Another way to think about this is that the population of our primary sampling unit is very large. Let’s say, therefore, that there is a very large number of schools (such as one million) in the population.

For many researchers, they treat the population as an infinitely large number, which is a conservative approach because it does not adjust the standard error to be smaller to account for the proportion of the population being sampled. For other researchers, such as for evaluations in a specific population—such as the schools in a particular state—the population size is finite. For instance, if there are 160 schools in a state and we’re only drawing inferences about schools in that state, we can this number as our population size, which will yield a lower standard error (which will narrow our confidence intervals compared to an infinite population size).

The following example treats the population as infinite (to follow Heeringa’s example), but in your own study, you can specify these sizes to match your needs in your research or evaluation.

To get this to work with the survey package, we create a column in the data that is this cluster N-size. Here, we can use N_cl as this column name to remind us that this is the population size of clusters.

dat$N_cl <- 1000000
head(dat)
##   sid school district score weight  N_cl
## 1   1      1        1  52.8      1 1e+06
## 2   2      1        1  32.5      2 1e+06
## 3   3      1        1  56.6      2 1e+06
## 4   4      1        1  47.0      1 1e+06
## 5   5      2        1  37.3      1 1e+06
## 6   6      2        1  57.0      1 1e+06

7.4.2 Step 1: Specifying the design

To use the srvyr package (and the survey package it wraps around), we need to create a survey-design object.32 This specifies what the survey design was when we collected the data, which in turn determines what kinds of adjustments to the standard error we should make.

Let’s create a survey-design object, with which we can perform subsequent calculations. We do this with the srvyr package’s as_survey_design() function. To remind us that this is a design and that it uses clusters, we can name our object des_cl, but you could call it Bill or mydesign.

library(survey)
library(srvyr)
des_cl <- dat %>% 
           as_survey_design(id = school, 
                           fpc = N_cl)

There are two arguments in that design specification. The id = specifies what the primary sampling unit is. In our design, the primary sampling unit (PSU) is the school variable in our data set. The second argument is for the finite population correction. We would think that the fpc = argument specifies the actual finite population correction, but it does NOT! Unintuitively, the default in the survey package is for fpc = to actually refer to the size of the population of primary sampling units. So, this should be called something like pop instead of fpc in the program—that would make it too easy, though, wouldn’t it.33 If the number of clusters in our population were finite, like 168 schools, we can use the fpc = 168 as a value for each case in the data set, which would make our standard error smaller. However, for this hypothetical example, we are saying there are 1 million schools.

We can look at the survey design we created using the summary() function on that object:

summary(des_cl) 
## 1 - level Cluster Sampling design
## With (8) clusters.
## Called via srvyr
## Probabilities:
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
##   8e-06   8e-06   8e-06   8e-06   8e-06   8e-06 
## Population size (PSUs): 1e+06 
## Data variables:
## [1] "sid"      "school"   "district" "score"    "weight"   "N_cl"

Notice that the probability of being sampled is equal across the quantiles. This is because everyone has the same fpc.

7.4.3 Step 2: Calculating the estimates

We want to know the mean and variance of our sample, as well as the confidence interval of the mean. We cannot use the regular Base R functions like mean() and variance() because they do not correct for the design. Instead, we use the functions from the svyr package. For example, instead of mean(), it uses survey_mean().34

des_cl %>% 
  summarize(survey_mean(score,                                 
                        vartype = c("se","ci"), df = degf(.),  
                        deff = TRUE ))
## # A tibble: 1 x 5
##    coef `_se` `_low` `_upp` `_deff`
##   <dbl> <dbl>  <dbl>  <dbl>   <dbl>
## 1  40.8  3.66   32.1   49.4    2.31

We have the summarize() function around the survey_mean() function. Just as we do in mathematics, we work from inside the parentheses to the outside. The first argument in the survey_mean() function is the variable that we are estimating, score in this case. The second argument specifies the type of sampling-distribution variance we would like to report (not to be confused with the sampling variance). Here, we seek the standard error ("se") and the upper and lower 95% confidence interval ("ci") based on the t distribution (based on the df = degf(.) argument). If we wanted the z distribution, we would remove the df = argument. Because t distribution values at the lower and upper 2.5% quantiles are larger in magnitude (depending on the degrees of freedom) than z distribution values (1.96), they are more conservative. We also request the design effect to be reported, deff = TRUE.

The coefficient of interest is the mean. The standard error and the lower- and upper-boundaries of the confidence intervals are reported, as well as the design effect.

We can actually save this output to an object and then use it later on. If you are like me, you think the outputs printed from the srvyr package are ugly. I want to see two decimal places, so I’ll round it to two decimal places, then print it with the print.data.frame() function.35

rslts_M_cl <- des_cl %>% 
          summarize(Mn = survey_mean(score, 
                         vartype = c("se","ci"), df = degf(.), 
                         deff = TRUE ) )
print.data.frame( round(rslts_M_cl, 2) )
##      Mn Mn_se Mn_low Mn_upp Mn_deff
## 1 40.77  3.66  32.12  49.42    2.31

Now let’s examine the variance and the sampling distribution of the variance. The function is survey_var():

rslts_V_cl <- des_cl %>% summarize(survey_var(score) )
print.data.frame( round(rslts_V_cl, 2) )
##     coef   _se
## 1 185.28 40.72

The coefficient is our estimated variance and the standard error is the standard error of the estimated variance.36

Conveniently, we can perform both the survey_mean() and survey_var() and save these to a report:

rslts_cl <- des_cl %>% 
          summarize(Mn = survey_mean(score, 
                         vartype = c("se","ci"), df = degf(.), 
                         deff = TRUE ),
                    Var= survey_var(score) )
print.data.frame(round(rslts_cl, 2))
##      Mn Mn_se Mn_low Mn_upp Mn_deff    Var Var_se
## 1 40.77  3.66  32.12  49.42    2.31 185.28  40.72

So, we have an estimated mean of the score (whatever construct this happens to be, such as students’ judgments of school climate) of \(40.77\) and a 95% confidence interval of \(( 32.12, 49.42)\).

7.4.4 Effective sample size

We can calculate the effective sample size from the number of students within the clusters, n, and the design effect. This is helpful for explaining the design effect to folks such as school personnel. First, let’s get the n-size of students.

To specify what the sample size of our smallest units (students) is, we can count the number of rows in the data using nrow(dat). This is useful if each row is an individual person. We can also use length(unique(dat$sid)) to count the number of observations that are unique in the student ID column.37 Either way, we get the same number.

n <- length(unique(dat$sid)) 
n
## [1] 32

As expected, there are 32 units (students) in our sample. Here’s the effective sample size, which is calculable as \(\frac{n}{\text{design effect}}\).38

rslts_cl <- rslts_cl %>% mutate(EffSS = n/Mn_deff)
print.data.frame(round(rslts_cl, 2))
##      Mn Mn_se Mn_low Mn_upp Mn_deff    Var Var_se EffSS
## 1 40.77  3.66  32.12  49.42    2.31 185.28  40.72 13.84

The standard error with this design is about what it would be with a simple random sample of \(13.84\) (or rounding up, \(14\)) students from the population. This shows the penalizing effect that we have correctly applied to the data.

Sometimes we want to also report the mean per school. We can use the group_by() function to specify what the grouping is before we apply the functions. Here, we’re grouping by school, then estimating the mean and variance39:

M_by_schl <- des_cl %>%

7.4.6 Two-stage cluster-sampled design

The method so far has assumed that the units within the clusters were the population within those clusters. For example, if we surveyed all of the students in our selected schools. In a two-stage design, we have the extra step of randomly selecting units within the clusters.

We first have to prepare the data. Let’s pretend we had a population of 100 students within each school from which we had randomly sampled. It is super unlikely that we’d ever have a data set with the same population size in all of the schools. This is only a demonstration—in our actual schools, we will probably know the total number in each school. There are big schools and small schools.

dat$N_cl_s <- 100

Now, we can use this column in the data set.

In the design, we specify column that identifies the within-cluster elements that were randomly selected from each cluster. Here it is sid in the id = line. Also, in the fpc = line, we specify the column in the data that includes the n-size within each cluster. For each of these two lines, the first argument is the primary sampling unit (the clusters) and the second is the within-cluster element—the secondary sampling unit.

des_cl2 <- dat %>% 
               as_survey_design(id = c(school, sid), 
                               fpc = c(N_cl, N_cl_s))
summary(des_cl2) 
## 2 - level Cluster Sampling design
## With (8, 32) clusters.
## Called via srvyr
## Probabilities:
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
## 3.2e-07 3.2e-07 3.2e-07 3.2e-07 3.2e-07 3.2e-07 
## Population size (PSUs): 1e+06 
## Data variables:
## [1] "sid"      "school"   "district" "score"    "weight"   "N_cl"     "N_cl_s"
rslts_cl2 <- des_cl2 %>% 
          summarize(Mn = survey_mean(score, 
                         vartype = c("se","ci"), df = degf(.), 
                         deff = TRUE ),
                    Var= survey_var(score) )
rslts_cl2 <- rslts_cl2 %>% mutate(EffSS = n/Mn_deff)
print.data.frame(round(rslts_cl2,2))
##      Mn Mn_se Mn_low Mn_upp Mn_deff    Var Var_se EffSS
## 1 40.77  3.66  32.12  49.42    2.31 185.28  40.72 13.84

The results are not that different from the single-stage cluster-sample design we just analyzed—in fact, they appear to be identical in this particular case.40 Again, this is an artificial data set. In a clinical setting, we would expect the results to differ because the number of secondary sampling units will likely differ across clusters. That is the N_cl_s of students within one school will differ from the N_cl_s of students in another school.

7.5 Stratified design

The strata are districts. In this sampling design, we are randomly selecting students from each stratum and pretending that the school cluster did not exist when we designed and carried out this sampling plan.

7.5.1 Preparing our data set

Again, we’ll effectively make the finite population correction negligible and assume that the population is big. This yields a more conservative confidence interval than if we had specified a smaller finite population, which would likely be the case if we were sampling from districts that were small.

Here, our primary sampling unit is the lowest element of our sampling plan. In other words, we had sampled the students from the strata. In the data set, each student is a row.

We need to specify how many sampled units are in each stratum. In other words, how many students are in each district. Normally, there will be a different number of students in a district (some districts are large; some are small). Here, for convenience (and to replicate the results in Heeringa and colleagues’ chapter), we will make them all very large, maybe something like 25,000,000 students in each district. In the column in the data, we can think of the students as coming from their district of this population size.

Traditionally, h stands for stratum in research designs. So, we’ll call our object des_h to help us remember it is a stratified design.

dat$N_h <- 25000000

7.5.2 Step 1: Specifying the design

Notice that we have three arguments: id = 1 to specify that the primary sampling unit is each row in the data set.41 The strata = district specifies the stratum. The fpc = N_h specifies the column in our data that includes the population size of each stratum.

des_h <- dat %>% 
  as_survey_design(id = 1, 
                   strata = district,
                   fpc = N_h)
summary(des_h)

Again, in our particular example, we’re saying each stratum has the same number of students but if we had a different population size in each stratum, we could specify data$N_h to be that number within each stratum. For example, if District 1’s population were small, with 1,000 students, all the students in our sample would have N_h = 1000; if District 2 were larger, with 20,000 students, the students in this district in our sample have N_h = 20000.

7.6 Stratified cluster-sampled design

In this design, the clusters were randomly sampled from each stratum. In this artificial data set, there were four districts and from each district, two schools were randomly selected from the sampling frame that contained the list of all schools in the population (by district).

7.6.1 Preparing the data

In the data set, we need to specify the number of clusters per stratum. For this example, to make it consistent with what Heeringa and colleagues present in their chapter, we set the population as very high. This results in a negligible (tiny) finite population correction. Let’s use something like n/N = 0.000008 for each stratum, which would occur if we had n = 2 schools in each stratum’s sample and N = 250,000 schools in its population.

dat$N_hcl <- 250000

So, we have a column in our data that we will use to say that there are 250,000 schools in each stratum.42

7.6.2 Step 1: Specifying the design

The design step is similar to what we used in the other cluster-sampled and stratified designs. Here, the variable used as the primary sampling unit is school, which is what id = school refers to. The stratum variable in the data set is district, strata = district, and the population size of each stratum is the column in the data we just created, fpc = N_hcl.

des_hcl <- dat %>% 
  as_survey_design(id = school,
                   strata = district,
                   fpc = N_hcl)
summary(des_hcl)

##            1 2 3 4

## design.PSU 2 2 2 2

## [8] "N_h"      "N_hcl"

We can see the sample sizes of the strata and the primary sampling unit (PSU) per stratum. This very simple example has only two clusters (schools) within each stratum (district).

7.6.3 Step 2: Calculating the estimates

This step is the same as the other designs above. We can also tag on the effective sample size.

rslts_hcl <- des_hcl %>% 
        summarize(Mn = survey_mean(score, 
                       vartype = c("se","ci"), df = degf(.), 
                       deff = TRUE ),
                  Var= survey_var(score) )
# effective sample size
n <- length(unique(dat$sid))

7.6.4 Mean per stratum

If our only objective is to draw inferences about the population, we can stop there. Sometimes, we also seek to report the mean per stratum. We can group by the stratum variable—district in this case—and estimate the means and variances. These estimates are what were combined in the estimate of the entire population.

M_by_Dist_cl <- des_hcl %>% 
             group_by(district) %>% 
               summarize(Mn = survey_mean(score),

7.7 A simple random sample design, for comparison

The simple random sample design assumes that the students were randomly drawn from a population of students. There is no clustering or stratification in the design or analysis.

7.7.1 Preparing our data set

We can, of course, simply use Base R functions to estimate the mean and variance and then calculate the standard error as \(\sqrt{\frac{Var}{n}}\) and then use the calculations we used in the prior chapter. However, the srvyr package also allows us to use the finite population correction.

If we assumed the population were huge, our finite population correction would be negligible. Let’s do this:

n <- length(unique(dat$sid)) # sample n
dat$N <- 10^8 # Population N
des_srs <- dat %>% 
               as_survey_design(id = 1, fpc = N)
rslts_srs <- des_srs %>% 
        summarize(Mn = survey_mean(score, vartype = c("se","ci"), df = degf(.)),
                  Var= survey_var(score)) 
rslts_srs <- rslts_srs %>% 
               mutate(EffSS   = n,
                      Mn_deff = 1)
print.data.frame( round(rslts_srs, 2) )
##      Mn Mn_se Mn_low Mn_upp    Var Var_se EffSS Mn_deff
## 1 40.77  2.41  35.86  45.68 185.28  45.96    32       1

Notice that the results are similar to the results we’d get using the procedures in the previous chapter.

score_M  <- mean(dat$score)
score_sd <- sd(dat$score)
score_n  <- nrow(dat)
score_se <- score_sd/sqrt(score_n)
LB_t     <-  score_M - qt(0.975, df = score_n -1)*score_se
UB_t     <-  score_M + qt(0.975, df = score_n -1)*score_se
round((c(M = score_M, var = score_sd^2, n = score_n, se = score_se, 
   CI_upper = LB_t, CI_lower = UB_t)), 2)
##        M      var        n       se CI_upper CI_lower 
##    40.77   185.28    32.00     2.41    35.86    45.68

If our finite population were small, such as N = 100, our standard error would be smaller and our confidence interval would be narrower, indicating our estimate of the mean is a more precise measure of a population of size 100.

dat$N2 <- 100 # Small Population N
des_srs2 <- dat %>% as_survey_design(id = 1, fpc = N2)
rslts_srs2 <- des_srs %>% 
        summarize(Mn = survey_mean(score, vartype = c("se","ci"), df = degf(.))) 
print.data.frame( round(rslts_srs2, 2) )
##      Mn Mn_se Mn_low Mn_upp
## 1 40.77  2.41  35.86  45.68

So, even though we can use Base R to estimate the confidence interval of a simple random sample, the survey and srvyr packages allow us to account for the finite population correction.
