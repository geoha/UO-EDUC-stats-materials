Chapter 3 Creating Custom Functions

It is tedious to write the same set of functions for several variables. In R, we can make our own custom functions. Let’s practice making one that we can use to report the descriptive statistics. We are assigning our function to an object called MyDesc, which is our own arbitrary name.


 We should use names for our custom functions that are not used for existing functions. For example, we would not want to call our function summary or mean because those are already taken.

We use the function() function and specify one or more arguments in the parenthesis, separated by commas. Here, we’re only specifying one argument, with the arbitrary letter x, which is pretty standard in functions to represent the data upon which we intend to use the function. We then use a bunch of functions (on x) inside our function, between the curly braces { and } and create objects. When we run the function, it replaces x with whatever argument we put inside the function. So, in a minute, we will use this code: MyDesc(dat$Read), which is short for MyDesc(x = dat$Read). The x in our function gets replaced by dat$Read.

MyDesc<- function(x) {
   n    <- sum(!is.na(x))
   M    <- mean(x,   na.rm = TRUE)
   min  <- min(x,    na.rm = TRUE)
   max  <- max(x,    na.rm = TRUE)
   med  <- median(x, na.rm = TRUE) 
   varp <- var(x,    na.rm = TRUE)*(n-1)/n
   sdp  <- sqrt(varp)
round( c(n=n, mean=M, median=med, min=min, max=max, 
         varp=varp, sdp=sdp ), 2)
   }

The last line in a custom function is used to return the set of objects. We could have included just the combine function with the objects such as c(n, M, med, min, max, varp, sdp ) but that would have resulted in a report that did not label the objects. The c(n=n, mean=M, median=med,... adds the labels n, mean, median,... and so forth to our output. We also decided to round the results to two decimal places. We could have removed that and just had c(n=n, mean=M, median=med, min=min, max=max, varp=varp, sdp=sdp ) as the last line. So, we used the combine function, c(), assigned labels to the objects, and rounded the values.26 Let’s try out our custom function:

MyDesc(dat$Read)
##      n   mean median    min    max   varp    sdp 
## 167.00  54.64  54.00  14.00  86.00 239.04  15.46

3.1 Using our function on multiple variables

Let’s try it out on our four variables that we used in the previous correlation matrix, the names of which we had already assigned to the object myvarbs using myvarbs <- c("Read", "Math", "Sci", "Schl_climate"). So, our data will be dat[, myvarbs].27

We can use the apply() function, which we practiced in the Getting Started with R for Measurement tutorial.28

Desc_scores<- apply(dat[ ,myvarbs], 2, MyDesc)
Desc_scores
##          Read   Math    Sci Schl_climate
## n      167.00 167.00 156.00       166.00
## mean    54.64  50.20  59.54        73.76
## median  54.00  50.00  61.00        73.00
## min     14.00   5.00  20.00        48.00
## max     86.00  88.00 100.00        94.00
## varp   239.04 266.26 311.58        53.07
## sdp     15.46  16.32  17.65         7.29

Maybe we want to transpose this output so the variables are rows and the descriptives are columns. We can use the transpose function, which is t():

t(Desc_scores)
