If we had these data in a CSV file, we could import them. With this small set of frequency data, we can imput them directly in R. Let’s use the c() function to assign the two columns of data to objects.

Score     <- c(36, 35, 34, 33, 32, 31, 30, 29, 28, 27, 26, 25)
Frequency <-  c(2,  2,  6,  2,  2,  3,  7,  5,  5,  7,  8,  3)
# I visually lined up the commas with these two objects (adding spaces) to be sure they're the same length.

Let’s combine these objects into a dataframe using the data.frame() function. We can do this because the objects Score and Frequency are vectors of the same length. The objects’ names become their column names in the new data frame. We can name our data frame dat2.1 to remind us we’re using Table 2.1.1

dat2.1 <- data.frame(Score, Frequency)

Let’s create and append a cumulative frequency variable to our data frame, to match the third column in Table 2.1. Here, we’re using the cumsum() function to get the cumulative frequency of each row and all of those before it.

dat2.1$cf    <- cumsum(dat2.1$Frequency)
# take a look:
head(dat2.1)
##   Score Frequency cf
## 1    36         2  2
## 2    35         2  4
## 3    34         6 10
## 4    33         2 12
## 5    32         2 14
## 6    31         3 17

Notice that this is not what we want. We want the cumulative frequency to be from the lowest to the highest scores. After an online search, I discovered we can use combination of functions rev(cumsum((rev(x)))) (with x representing the column we need to perform the operation on). I assume the rev() function reverses something in our function—I haven’t seen that function until now (I can use ?rev in the console to learn more). Let’s try this new code:

dat2.1$cf    <- rev(cumsum((rev(dat2.1$Frequency))))
head(dat2.1)
##   Score Frequency cf
## 1    36         2 52
## 2    35         2 50
## 3    34         6 48
## 4    33         2 42
## 5    32         2 40
## 6    31         3 38

That’s more like it.2

The other three columns in Figure 2.1 are percentage, cumulative percentage, and percentile rank. We first need the total n size, which is the sum of the frequency column. We can use this in the denominator of the next two lines.

n <- sum(Frequency)
dat2.1$Perc  <- dat2.1$Frequency/n*100
dat2.1$CPerc <- dat2.1$cf/n*100
head(dat2.1)
##   Score Frequency cf      Perc     CPerc
## 1    36         2 52  3.846154 100.00000
## 2    35         2 50  3.846154  96.15385
## 3    34         6 48 11.538462  92.30769
## 4    33         2 42  3.846154  80.76923
## 5    32         2 40  3.846154  76.92308
## 6    31         3 38  5.769231  73.07692

Using the calculation described in Bandalos, we can get the percentile rank as the cumulative frequency of the scores below that particular score plus half of the number of scores at the score of interest. We can use a proportion instead of a percentile rank so we can use it to get normal Z scores (coming up next). We’ll calculate this as \(PR = \frac{cf_{below}+ \frac{Frequency}{2}}{n}\), where \(cf_{below}\) is the cumulative frequency of the score that is below the one of interest. Rather than reference that lower row, we can use the present row’s cf and subtract its frequency, \(cf_{below} = cf - Frequency\).

dat2.1$PR    <- ((dat2.1$cf - dat2.1$Frequency) + dat2.1$Frequency/2) / n

Let’s calculate the Normalized scores. These are the normal Z scores, normal curve equivalents (NCE), and normalized T scores. Note that these are based on the percentile rank, making these Z and T scores normalized.3 To get the Znorm score, we use the qnorm() function, whose first argument is a percentile rank4, the mean, and the standard deviation.

dat2.1$Znorm <- qnorm(dat2.1$PR, 0, 1)
dat2.1$NCE   <- dat2.1$Znorm*21.06 + 50 # Or, we could use qnorm(dat2.1$PR, 50, 21.06).
dat2.1$T     <- qnorm(dat2.1$PR, 50, 10)

Here is all of our code in one chunk. Although this is easier to do in Excel with our specific data set, we can keep our code in case we find errors5 and reuse this code with other data sets. See if you can use this code for Table 2.3 in the exercises of Chapter 2.

Score     <- c(36, 35, 34, 33, 32, 31, 30, 29, 28, 27, 26, 25)
Frequency <-  c(2,  2,  6,  2,  2,  3,  7,  5,  5,  7,  8,  3) 
dat2.1    <- data.frame(Score, Frequency)
dat2.1$cf <- rev(cumsum((rev(dat2.1$Frequency))))
n         <- sum(Frequency)
dat2.1$Perc  <- dat2.1$Frequency/n*100
dat2.1$CPerc <- dat2.1$cf/n*100
dat2.1$PR    <- ((dat2.1$cf - dat2.1$Frequency) + dat2.1$Frequency/2) / n
dat2.1$Znorm <- qnorm(dat2.1$PR, 0, 1)
dat2.1$NCE   <- dat2.1$Znorm*21.06 + 50 # Or, we could use qnorm(dat2.1$PR, 50, 21.06).
dat2.1$T     <- qnorm(dat2.1$PR, 50, 10)
round(dat2.1, 2)

1.2 Run-of-the-mill Z scores

You may be wondering about the typical non-normalized Z scores. Here they are. We first calculate the mean (\(\bar{X}\)) and the standard deviation (\(S\)) to get the Z score of a person i with a particular score, \(Z_i = \frac{X_i - \bar{X}}{S}\). Each person with the same score has the same Z score. Notice that these are not the same as the normal Z scores. The mean is 29.54 and standard deviation is 3.21.

M  <- 29.54
SD <- 3.21
dat2.1$Z <- (dat2.1$Score - M)/SD
head(dat2.1)

1.3 Extra optional stuff

If you wanted to transform our frequency data from Table 2.1 into a full data set, you could do it manually, but it’s more fun to use a function. I did an online search and found that the expand.dft() function from the vcdExtra package would do the trick. From that case-wise data set, we can easily calculate the mean and standard deviation, which is how I got these for calculating the run-of-the-mill Z scores above.6

# install.packages("vcdExtra") # Uncomment this out and run it only once on your machine.
library(vcdExtra)
Case2.1 <- expand.dft(dat2.1, freq="Frequency")
M  <- mean(Case2.1$Score)
SD <- sd(Case2.1$Score)
