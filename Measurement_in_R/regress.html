5.1 The lm() function

We can regress Y on X using the linear model function, lm(). Here is an example using our data from the Variance, Covariance, Correlation section:

Let’s regress Math on Title I status. To make our intercept meaningful, let’s create a new numeric variable that is 1 if Title I is Yes and 0 otherwise.

dat$Title1 <- ifelse(dat$Title_I == "Yes", 1 ,0)

We used the ifelse() function here. Note that we need a double equals signs in our logical test. Now, let’s run the linear model. Notice that there’s a data = argument. This is convenient so we do not have to keep typing dat$ before every variable.34

lm(Math ~ Title1, data = dat)
## 
## Call:
## lm(formula = Math ~ Title1, data = dat)
## 
## Coefficients:
## (Intercept)       Title1  
##       62.57       -19.86

Boy, that’s sparse! All we get are coefficients.

We can use the summary() function to examine the output we’re used to. We can assign the output of the lm() function to an object and run summary() on that object:

fit1 <- lm(Math ~ Title1, data = dat)
summary(fit1)
## 
## Call:
## lm(formula = Math ~ Title1, data = dat)
## 
## Residuals:
##     Min      1Q  Median      3Q     Max 
## -37.712  -8.712   0.288   8.788  36.288 
## 
## Coefficients:
##             Estimate Std. Error t value Pr(>|t|)    
## (Intercept)   62.571      1.670  37.468   <2e-16 ***
## Title1       -19.860      2.116  -9.385   <2e-16 ***
## ---
## Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
## 
## Residual standard error: 13.26 on 165 degrees of freedom
##   (1 observation deleted due to missingness)
## Multiple R-squared:  0.348,  Adjusted R-squared:  0.3441 
## F-statistic: 88.07 on 1 and 165 DF,  p-value: < 2.2e-16

In the output, the intercept 62.57 is the expected value of the Math when Title I is zero. In other words for schools that are not qualified to receive Title 1 funding, the mean Math proficiency rate is 62.57%. For schools with Title I status, the predicted proficiency rate on this test is estimated to be lower by 19.86 percentage points. The standard error of the predictor is 2.12, which is low compared to the magnitude of the estimated slope of -19.86. So, we can be confident that the relationship is not a random fluke. If we devide the estimate by the standard error, we get the test statistic of -9.38, which is statistically significant at alpha = .05.

5.2 Using the regression parameters for prediction

If we wish to use the regression parameters to predict the expected value of an outcome variable, \(\hat{Y}\) , given a value on one or more predictors, we can use the predict() function with an argument newdata =. For example, we can use this code to get the predicted value when Title1 = 1,

predict(fit1, newdata = data.frame(Title1 = 1))
##        1 
## 42.71154

This is the same result as if we had used hand calculations using the estimated parameters:

X <- 1
PredY <- 62.571 + -19.860*X
PredY
## [1] 42.711

With this particular example, there are only two values of a single predictor, 1 and 0, but for other models, we can also use a data frame to estimate the expected values. For instance, if we had a five schools, with respective Title1 statuses of Yes, No, No, Yes, and Yes, we could retrieve their predicted values. In this code, we’ll assign the values to a variable with the same name as the predictor, Title1, and then coerce it into a data frame, X.

X <- data.frame(Title1 = c(1, 0, 0, 1, 1))
predict(fit1, newdata = X)
##        1        2        3        4        5 
## 42.71154 62.57143 62.57143 42.71154 42.71154

We can also request the predicted outcome \(\hat{Y}\) of a subset of rows from a data frame. For instance, if we know that we would like the predicted math proficiency percentages of schools with Schl_id of 100 and 107 from our original data, we can use this code. Here, we’re asking for a subset of data in which the Schl_id variables are 100 or 107. The double equals sign == is for logical testing. Other rows for which this result is false are excluded and do not enter into our subset.

X <- dat[dat$Schl_id == c(100, 107), ] 
# Note that Schl_id is a numeric variable, so we don't use quotes
predict(fit1, newdata = X)
##        1        4 
## 62.57143 42.71154

We can also subset by other variables. And, we can append this output to the data frame of the same length. Here’s a subset of all of those schools from a particular county and their predicted percentages of mathematics proficiency rates:

X <- dat[dat$County == "Kauai", ]  
# notice that County is a character type of variable, so we need quotes.
X$Pred_Math <- predict(fit1, newdata = X)

5.3 Model error variance and a peek into classical test theory

Notice the model has a residual standard error of 13.26. If we examine the ANOVA table from the model, we see that this is the root of the mean square error, 175.7. So, the residual standard error is the root mean square error and is in the same units as those in the dependent variable, Math in this case.

anova(fit1)
## Analysis of Variance Table
## 
## Response: Math
##            Df Sum Sq Mean Sq F value    Pr(>F)    
## Title1      1  15474 15474.3  88.072 < 2.2e-16 ***
## Residuals 165  28991   175.7                      
## ---
## Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

We can think back to our ANOVA and regression classes and think of the mean square error as the error variance of the model. It is the variance in math proficiency rates that is not explained by variation in Title I status. The idea is that Y is explained by the model plus some error, \(Y = Model + Error\). In terms of sums of squares, \(SS_{total} = SS_{model} + SS_{error}\). In examining the statistical significance of the model (but not so much in measurement), people use the F statistic \(F = \frac{MS_{model}}{MS_{error}}= \frac{1.54743\times 10^{4}}{175.7}\), which is a ratio of the explained-to-unexplained variance, or signal-to-noise ratio.

This way of thinking about how total variance comprises systematic and unsystematic variance will be revisited in discussions about classical-test-theory reliability, where it is assumed that \(\sigma^2_{total} = \sigma^2_{true} + \sigma^2_{error}\) and that \(reliability = \frac{\sigma^2_{true}}{\sigma^2_{total}}\).

  1. The tilde, ~, is used in R to indicate a formula. We will see this in regression and other statistical equations, where it serves the same role as the “=” operator (e.g.,\(Y \sim b_0 + b_1X\)). Here, we’re asking R to regress Math on Title1.↩︎
