Using R for Measurement in the Social Sciences

Chapter 10 Inter-rater and Test-retest Reliability

In this chapter, we expand our understanding of reliability to include inter-rater reliability and agreement. We will begin with coefficient kappa (\(\kappa\)), which also called Cohen’s \(\kappa\), to estimate inter-rater agreement with nominal data. We’ll then practice estimating inter-rater reliability and agreement with the intraclass correlation coefficient (ICC), which we will also see can be used to estimate test-retest reliability.

10.1 Coefficient kappa for estimating agreement with nominal data

Coefficient \(\kappa\) is appropriate for estimating agreement between raters when the data are nominal. This is appropriate when we plan to use the instrument to make classification decisions about persons, such as in determining whether each person has met a criterion.

To estimate inter-rater agreement using \(\kappa\), we first create a contingency table of the frequency of ratings by each rater. We can do this manually by creating a table and counting the number of agreements and disagreements for each of the two categories, resulting in a four-cell table. We can also use R. Let’s look at some classification data:

dat <- read.csv("Week07 essays.csv")
str(dat)
## 'data.frame':    100 obs. of  5 variables:
##  $ r1    : int  5 4 4 1 3 2 0 6 4 5 ...
##  $ r2    : int  4 3 3 0 2 0 0 5 4 4 ...
##  $ r3    : int  3 3 3 2 3 1 1 5 4 4 ...
##  $ judge1: chr  "Pass" "Pass" "Pass" "Fail" ...
##  $ judge2: chr  "Pass" "Pass" "Pass" "Fail" ...

The pass and fail data are what we are interested in. Let’s create a contingency table using the table() function from Base R:

judges <- c("judge1", "judge2")
judge_tab <- table(dat[, judges])
judge_tab
##       judge2
## judge1 Fail Pass
##   Fail   15    1
##   Pass   21   63

It looks like the two judges agree on 15 cases about failure and 63 cases on passing. They disagree on some fails and passes, with Judge 1 assigning passes to people that Judge 2 assigned fails to. Let’s examine the proportion table:

judge_tab/sum(judge_tab)
##       judge2
## judge1 Fail Pass
##   Fail 0.15 0.01
##   Pass 0.21 0.63

Alternatively, we can use the prop.table() function on the original table:

judge_tab_p <- prop.table(judge_tab)
judge_tab_p
##       judge2
## judge1 Fail Pass
##   Fail 0.15 0.01
##   Pass 0.21 0.63

We can get the nominal agreement estimate by summing the diagonal on the proportion table.

P_o    <- sum(diag(judge_tab_p))  #Summing the diagonal
P_o
## [1] 0.78

The two judges agreed with each other 78% of the time. However, there is also chance agreement.78

#By-chance agreement:
P_c<- sum(judge_tab_p[1,]) * sum(judge_tab_p[,1]) +
      sum(judge_tab_p[2,]) * sum(judge_tab_p[,2])
P_c
## [1] 0.5952

Now our earlier estimate of agreement does not seem so high given the high probability of agreement from chance. We can adjust our agreement coefficient by the chance probability to get \(\kappa\):

Kappa<- (P_o - P_c)/(1-P_c)
Kappa
## [1] 0.4565217

10.1.1 Using the irr package to estimate kappa

If we’re feeling lazy, we can use kappa2() function from the irr package (Gamer et al., 2019) to estimate \(\kappa\):

library(irr)
kappa2(dat[, judges])
##  Cohen's Kappa for 2 Raters (Weights: unweighted)
## 
##  Subjects = 100 
##    Raters = 2 
##     Kappa = 0.457 
## 
##         z = 5.25 
##   p-value = 1.51e-07

We can also use it to estimate agreement:

irr::agree(dat[, judges])
##  Percentage agreement (Tolerance=0)
## 
##  Subjects = 100 
##    Raters = 2 
##   %-agree = 78

10.1.2 Limitations of kappa

One limitation of \(\kappa\) is that it is based on the assumption that the raters are fixed, rather than being a random sample of possible raters. This means that we cannot interpret a \(\kappa\) coefficient as an indicator of how accurate the rating procedure is with raters who were not included in our nominal agreement study.

It is also important to remember that \(\kappa\) is for nominal data. If the raters are rating persons on multiple yes-or-no items, we would need to report \(\kappa\) for each item. This coefficient does not, therefore, reveal an overall estimate of rater agreement across multiple items. For that, we would use generalizability theory, which we look into in the next chapter.

10.2 Intraclass correlation coefficients for estimating consistency and agreement

Though some researchers simply use a correlation coefficient for inter-rater reliability79, there is a special class of reliability coefficients for inter-rater reliability, falling under the name intraclass correlation coefficient (ICC).

There are several ICC models we can use for inter-rater reliability. The one we use should depend on the nature of our data and the intended interpretations of the test scores.

The most important distinguishing characteristic is probably whether we are considering consistency and agreement, or just consistency. Consistency is important for test-score interpretations that concern persons’ relative standing in the population of persons.80 An example in which consistency is important is when we collect test scores that we will subsequently use as a dependent variable in a regression to test the effects of an intervention study. This takes an ICC model that accounts for consistency, or relative decisions.

Agreement is important for test-score interpretations that are criterion-referenced in nature. An example in which agreement is important might be when we have a panel of raters rate students’ writing skills in their essays to determine whether to place the students into a beginner, intermediate, or advanced level writing class. This takes an ICC model that accounts for agreement, or absolute decisions.

10.2.1 Example of an ICC for consistency

Let’s look at an example of an ICC that we would use for estimating the reliability of scores used for relative decisions. Let’s import the data from Table 9.1 of Bandalos (2018).

datW <- read.csv("Week07 Table9.1W.csv")
datW
##    person rater1 rater2 rater3
## 1       1      1      1      1
## 2       2      2      1      3
## 3       3      2      2      3
## 4       4      3      3      4
## 5       5      3      2      4
## 6       6      3      3      4
## 7       7      4      4      4
## 8       8      4      3      5
## 9       9      5      5      5
## 10     10      5      5      5

Notice how the raters are arranged so that each rater is allocated to their own column.81 In this manner, we can think of these three raters as being analogous to three items (or sub-tests). Because we have at least three raters and because every rater rated every person, we can actually use coefficient alpha to estimate inter-rater reliability if all we were interested in was consistency between raters. Remember the CTT package and our use of the itemAnalysis() function to get alpha? Here it is again. One could also use the psych package.

library(CTT)
CTT::itemAnalysis(datW[ , -1])$alpha
## [1] 0.9571106

This informs us of how consistent the raters are in rank-ordering persons.

If we use one of the ICC models, \(\text{ICC}_{Ck}\), we will arrive at this same estimate. This particular ICC model, \(\text{ICC}_{Ck}\), includes the subscripts \(C\) and \(k\), where \(C\) stands for consistency and \(k\) stands for scores averaged across raters. In other words, with this ICC, we’re interested in the consistency across raters, and when we calculate each person’s test score, we’ll use the average of the ratings that person received. This is pretty much what we do with a test comprising items that we sum to create a composite score.82 Here’s how this ICC is calculated. This formula might look familiar if you are accustomed to analysis-of-variance terminology.

\[ \text{ICC}_{\text{C,k}} = \frac{MS_B - MS_E}{MS_B} \] \(MS_B\) is the between-person variance and \(MS_E\) is error variance. This is analogous to classical test theory, in which we are seeking to estimate the ratio of the true-score to total-observed-score variance. With the ICC, we subtracting the error variance from the observed between-person variance in the numerator, which is analogous to true-score variance.

How do we estimate \(MS_B\) and \(MS_E\)? We can use ANOVA to get these, then examine the ratio and see if it is the same as what we saw with coefficient alpha. There’s something we need to do before we fit an ANOVA linear model. We need to reshape the data.

10.2.1.1 Reshaping data

In linear models, such as regression and ANOVA, our variables are columns. However, right now our data set has raters in separate columns. We need one column that includes all the raters (so each rater is a level in this factor). Then, we need a column that includes the rating. We need to reshape our data from wide to long. For this, we can use the pivot_longer() function from the tidyr package (Wickham, 2020c) which is part of the tidyverse set of packages.83 The argument key = is for us to name the new variable that will include the wide data set’s row names. We can name this “rater” or “Rater” or “judge” or whatever. The value = argument is for us to provide a name for the variable that will include the numeric score provided by the rater. We’ll use “score” but we could also use another name such as “rating”.

library(tidyverse)
datL <- datW %>% 
          pivot_longer(names_to = "rater", 
                      values_to = "score", 
                 rater1:rater3)

The data set is now in long format. Let’s use the head() and tail() functions to look at the first and last six rows:

head(datL)
## # A tibble: 6 x 3
##   person rater  score
##    <int> <chr>  <int>
## 1      1 rater1     1
## 2      1 rater2     1
## 3      1 rater3     1
## 4      2 rater1     2
## 5      2 rater2     1
## 6      2 rater3     3
tail(datL)
## # A tibble: 6 x 3
##   person rater  score
##    <int> <chr>  <int>
## 1      9 rater1     5
## 2      9 rater2     5
## 3      9 rater3     5
## 4     10 rater1     5
## 5     10 rater2     5
## 6     10 rater3     5

Notice that the names of the rater columns in the wide data set are now cell entries under the column rater in the long data set. Also, we created a variable called score. This is the same data set as is in Bandalos (2018) Table 9.4.84

To run factorial ANOVA with lm(), we need to make sure the persons and the raters are factors.85 This ensures that the lm() function will use dummy variables instead of numeric values.

str(datL)
## tibble [30 x 3] (S3: tbl_df/tbl/data.frame)
##  $ person: int [1:30] 1 1 1 2 2 2 3 3 3 4 ...
##  $ rater : chr [1:30] "rater1" "rater2" "rater3" "rater1" ...
##  $ score : int [1:30] 1 1 1 2 1 3 2 2 3 3 ...

It appears that our person variable is numeric and our rater variable is of character type. Let’s change these to factors:

datL$person <- factor(datL$person)
datL$rater  <- factor(datL$rater)
str(datL)
## tibble [30 x 3] (S3: tbl_df/tbl/data.frame)
##  $ person: Factor w/ 10 levels "1","2","3","4",..: 1 1 1 2 2 2 3 3 3 4 ...
##  $ rater : Factor w/ 3 levels "rater1","rater2",..: 1 2 3 1 2 3 1 2 3 1 ...
##  $ score : int [1:30] 1 1 1 2 1 3 2 2 3 3 ...

Now we can fit these to a factorial ANOVA model using the lm() function. We can then get the ANOVA table to see the mean squares:86

fit <- lm(score ~ person + rater, data = datL)
anovatab<- anova(fit)
anovatab
Df Sum Sq Mean Sq F value Pr(>F)
person 9 44.3 4.922 23.316 0.000
rater 2 4.2 2.100 9.947 0.001
Residuals 18 3.8 0.211

Compare this ANOVA table with Table 9.6 of Bandalos. The person variance, \(MS_B\), is 4.92. The error variance, \(MS_E\) is 0.21. The rater variance, \(MS_R\) is 2.1. The within-person variance is made up of variance due to raters and variance due to the residual (or error).

Our mission here is to calculate \(\text{ICC}_{Ck}\). Let’s plug these values into the equation: \[\begin{eqnarray*} \text{ICC}_{\text{C,k}} &=& \frac{MS_B - MS_E}{MS_B}\\[5pt] &=& \frac{\\4.92 - 0.21}{\\4.92}\\[5pt] &=& 0.9571 \end{eqnarray*}\]

This is the same result from our calculation of coefficient alpha. Our interpretation is that the inter-rater reliability estimate based on consistency and when scores are calculated as the mean across raters, \(\text{ICC}_{Ck}\), is .96, meaning that about 96% of the observed between-person variance is estimated to be explained by true-score variance. We could do this all in R by assigning these values to objects and then using them in our equation.

MSB <- anovatab["person",    "Mean Sq"] #MS Between persons
MSR <- anovatab["rater",     "Mean Sq"] #MS between Raters
MSE <- anovatab["Residuals", "Mean Sq"] #MS error
n <- length(levels(datL$person))        #Number of persons
k <- length(levels(datL$rater))         #Number of raters
# ICC(C,k):
(MSB - MSE) / MSB
## [1] 0.9571106

We have seen how the calculation for \(\text{ICC}_{Ck}\) yields the same result as coefficient alpha. This is only one of the ICC models. If we are also interested in rater agreement, coefficient alpha is not informative. Alpha and \(\text{ICC}_{Ck}\) will not detect if one rater is consistently stringent in their ratings and another is consistently lenient. For estimating inter-rater agreement, which are valuable for absolute decisions, we need to use one of the other ICC models.

10.2.2 Example of an ICC for agreement

Let’s see what the \(\text{ICC}_{Ak}\) is with this same data. We are now interested in rater agreement (for absolute decisions), which is what the \(A\) subscript in \(\text{ICC}_{Ak}\) stands for. What this means is that we now have to include rater variance as part of the total variance (the denominator) of our equation.

\[ \text{ICC}_{\text{A,k}} = \frac{MS_B - MS_E}{MS_B + (MS_R - MS_E)/n} \]

We could calculate this using the following code with the objects we created in our previous example:

# ICC(A,k):
(MSB - MSE) / (MSB + (MSR - MSE)/n )
## [1] 0.9217391

As expected this is lower than the estimate using only consistency. This is because \(\text{ICC}_{Ak}\) includes more variance in the denominator than does \(\text{ICC}_{Ck}\).

10.2.3 Two-way and one-way ICC models

So far, raters have been crossed with persons. In other words, each rater rated every person. In ANOVA terminology, these are two-way models because raters and persons are two factors.

In some designs, each person has their own set of raters. In that case, we cannot disentangle the rater variance from the error variance of the person. These are one way models because the person factor includes the variance of the raters. Together those two variances would constitute within-person variance, \(MS_W\), which we can place in the following equation. \(\text{ICC}_k\) cannot include consistency because none of the raters are shared across people, so consistency is a moot point; therefore, \(\text{ICC}_k\) is about agreement among the raters nested within persons.

We can calculate \(\text{ICC}_k\) using the within-person variance, \(MS_W\), in this formula: \[ \text{ICC}_{\text{k}} = \frac{MS_B - MS_W}{MS_B} \]

#MS within-person is (SSR + SSE)/(sum of df of the two):
SSW   <- sum(anovatab[c("rater","Residuals"), "Sum Sq"])
MSW_df<- sum(anovatab[c("rater","Residuals"), "Df"])
MSW   <- SSW/MSW_df
ICC_k <- (MSB - MSW)/MSB
ICC_k
## [1] 0.9187359

10.2.4 Single versus average ratings

It may also be the case that during our reliability study, we included several raters but that we wish to interpret how reliable these rating procedures would be with a single rater. This would be important if we needed to reduce costs with our operationalized instrument (raters can be expensive). It may also occur when a single teacher uses this with a class of students rather than all of school’s teachers performing the ratings. These are labeled as \(\text{ICC}_{C1}\) and \(\text{ICC}_{A1}\) for consistency and agreement respectively. The \(1\) subscript means that a single rater will be used.

10.2.5 All of the equations

Here are all of the equations for the ICC designs. The ICC labels we have been using are conventions used in McGraw and Wong (1996):

  • \(A\) is for agreement across raters, used for absolute decisions
  • \(C\) is for consistency across raters, used for relative decisions
  • \(1\) is for scores that will be from a single rater87
  • \(k\) is for scores that will be calculated from the average of multiple raters
# ICC(1)   One-way, absolute, single:
  ICC_1  <- (MSB - MSW) / (MSB + (k-1)*MSW)
# ICC(k)   One-way, absolute, average:
  ICC_k  <- (MSB - MSW) / (MSB) 
# ICC(A,1) Two-way, absolute, single:
  ICC_A1 <- (MSB- MSE)/(MSB + (k-1)*MSE + k/n*(MSR-MSE))
# ICC(A,k) Two-way, absolute, average:
  ICC_Ak <- (MSB - MSE) / (MSB+(MSR - MSE)/n)
# ICC(C,1) Two-way, consistency, single:
  ICC_C1 <- (MSB- MSE)/(MSB + (k-1)*MSE )
# ICC(C,k) Two-way, consistency, average:
  ICC_Ck <- (MSB - MSE) / (MSB)
Table 10.1: ICC models and their formula
ICC model Formula Estimate
ICC1 \(\frac{MS_B - MS_W} {MS_B + (k-1)MS_W}\) .79
ICCk \(\frac{MS_B - MS_W } { MS_B}\) .92
ICCA1 \(\frac{MS_B- MS_E} {MS_B + (k-1)MS_E + \frac{k}{n}(MS_R-MS_E)}\) .80
ICCAk \(\frac{MS_B - MS_E } { MS_B+(MS_R - MS_E)/n}\) .92
ICCC1 \(\frac{MS_B- MS_E} {MS_B + (k-1)MS_E }\) .88
ICCCk \(\frac{MS_B - MS_E } { MS_B }\) .96
Note. The ICC labels are from McGraw and Wong (1996).

10.2.6 Recommendations on reporting ICCs

Strictly speaking, these ICC models also include a specification for whether the raters are fixed or random. Fixed refers to the specific set of raters without any intention to generalize this reliability coefficient beyond our sample of raters. This might be the case for a job interview in which the raters are all part of the same organization. A random specification assumes that the raters were random draws from a population of raters—as would be the case with a large testing company that hires many essay raters. What is weird is that we use the same computations when we treat raters as fixed and as random. Therefore, this distinction is not present in the table nor in the options of some R packages (because what’s the point). However, when we write up our methods we still need to address whether we assume our raters are fixed or random, as that affects how we interpret the results.

Secondly, and perhaps worth stressing quite forcefully, whenever we report an ICC statistic, we need to state which model we used. For example, we might say this:

For our inter-rater reliability study, we examined not only consistency but also agreement across the raters. Every rater rated every person; thus, this was a fully crossed design resulting in a two-way intraclass correlation coefficient (ICC) model. We treated the raters as random because the raters in our reliability study were a sample from our population of raters. During the operational study, each person’s score will be calculated as the average across this same number of raters. Given this design, we estimated inter-rater reliability using the ICC, specifically the \(\text{ICC}_{A,k}\) model, the formula of which is described in McGraw and Wong (1996).

It is poor practice to simply report that the ICC was estimated without saying which ICC. These models differ in their estimates and implications.

Thirdly, there are at least two different conventions for labeling these ICC models. The ones here are from McGraw and Wong (1996). The labeling conventions of Shrout and Fleiss (1979) are also frequently used. It is worth stating, as we just did, which conventions we are using so readers know where to look if they’re familiar with the convention we are using.

Finally, when we use software, we need to report which package and procedure we used. The results from the irr package (Gamer et al., 2019) and the psych package (Revelle, 2020), for example, do not always seem to align.

10.3 Using the irr package

For the practitioner seeking to avoid deep understanding, this previous lengthy discussion about how to calculate the ICC can be skipped. For all of us, now that we have thought through these at least a little, we can use the icc() function of the irr package (Gamer et al., 2019).

For this function, we use data that are in the wide format. Let’s assign the names of our rater columns to an object, ratrs, bring the irr package into the library, and use the icc() function. The arguments are described in the help menus, but they are self explanatory. Let’s estimate \(\text{ICC}_{A,k}\) using this function by specifying type = "agreement" and unit = "average". We’ll also use model = "twoway" because the raters are crossed with people (again, all raters rated all persons).

ratrs      <- c("rater1", "rater2", "rater3")
library(irr)
icc(datW[,ratrs], model="twoway", type="agreement",   unit="average")
##  Average Score Intraclass Correlation
## 
##    Model: twoway 
##    Type : agreement 
## 
##    Subjects = 10 
##      Raters = 3 
##    ICC(A,3) = 0.922
## 
##  F-Test, H0: r0 = 0 ; H1: r0 > 0 
##   F(9,6.82) = 23.3 , p = 0.000245 
## 
##  95%-Confidence Interval for ICC Population Values:
##   0.663 < ICC < 0.981

The output tells us the model is two way of the agreement (rather than consistency) type. The ICC is labeled as ICC(A,3) with 3 referring to the number of raters. A confidence interval is also provided, which is worth reporting.

For the other models, we can use the following code after we have created our ratrs object and brought the irr package into our library:

icc(datW[,ratrs], model="oneway", type="agreement",   unit="single")
icc(datW[,ratrs], model="oneway", type="agreement",   unit="average")
icc(datW[,ratrs], model="twoway", type="agreement",   unit="single")
icc(datW[,ratrs], model="twoway", type="agreement",   unit="average")
icc(datW[,ratrs], model="twoway", type="consistency", unit="single")
icc(datW[,ratrs], model="twoway", type="consistency", unit="average")

Typically, we only use one of these lines of code becuase our inter-rater reliability study usually is concerned with only one of them. All of them are presented here for easy reference.

10.4 Test-retest reliability

Test-retest reliability in classical test theory is very straightforward: It is the Pearson correlation between the two tests. Each person takes the first and second test.

This is analogous to having two raters test each person. We can perform the same calculations as we did with raters. A benefit to using the ICC is that we can also estimate the “agreement” across the two time points. This may be valuable when we seek to examine the stability of the instrument over time not only in how it ranks persons but in whether there is slippage in how difficult or easy the test is over time. For instance, if everyone’s second-occasion test were exactly 10 points higher than that of their first occasion, we would observe perfect consistency, but the agreement ICC coefficient would probably be low. This is a very good reason for using ICCs instead of Pearson’s correlation for test-retest reliability. Researchers using quasiexperimental designs with multiple pretests may wish to report this type of test-retest agreement to argue that some effects, such as maturation in the construct that the true scores are purported to measure, are not unduly affecting the changes in scores in their operational use of the test to detect change from an intervention.

One thing we should be sure to do is to use the single rating specification, \(\text{ICC}_{C1}\) and \(\text{ICC}_{A1}\). This is because the way we will use the instrument in our operational study (after completing the reliability study) is we will measure the participants on one occasion, get a score, then provide some kind of intervention, and then use the test again. It would make little sense to use the average scores of two occasions of the test, so the average measure should not be used for test-retest reliability.

Let’s use our data set as an example and pretend that Raters 1 and 2 are actually two different occasions, Time 1 and Time 2. We can estimate test-retest reliability using \(\text{ICC}_{C1}\).

datW$time1 <- datW$rater1
datW$time2 <- datW$rater2
icc(datW[ , c("time1", "time2") ], model="twoway", type="consistency", unit="single")
##  Single Score Intraclass Correlation
## 
##    Model: twoway 
##    Type : consistency 
## 
##    Subjects = 10 
##      Raters = 2 
##    ICC(C,1) = 0.939
## 
##  F-Test, H0: r0 = 0 ; H1: r0 > 0 
##      F(9,9) = 31.9 , p = 9.08e-06 
## 
##  95%-Confidence Interval for ICC Population Values:
##   0.776 < ICC < 0.985

The test-retest reliability estimate with \(\text{ICC}_{C1}\) is .94. Here’s the test-retest agreement coefficient, using \(\text{ICC}_{A1}\):

icc(datW[ , c("time1", "time2") ], model="twoway", type="agreement", unit="single")
##  Single Score Intraclass Correlation
## 
##    Model: twoway 
##    Type : agreement 
## 
##    Subjects = 10 
##      Raters = 2 
##    ICC(A,1) = 0.923
## 
##  F-Test, H0: r0 = 0 ; H1: r0 > 0 
##   F(9,7.12) = 31.9 , p = 6.38e-05 
## 
##  95%-Confidence Interval for ICC Population Values:
##   0.689 < ICC < 0.981

We can see that the absolute agreement is pretty high. This is because for several persons, several of the scores were the same in both time points (as Bandalos points out with this example data set).
