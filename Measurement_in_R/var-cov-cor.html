2.1 Correlation

A common method for estimating correlation is to use the cor() function in base R.

To estimate the Pearson correlation between two variables, we can use the cor() function. Of course, we have to specify what those two variables are. Let’s estimate the correlation between Read (which is the percentage of students in the school meeting language-arts proficiency) and Schl_climate (which is the school’s score from a school climate survey):

cor(dat$Read, dat$Schl_climate,
    use = "complete.obs")
## [1] 0.4638681

The Pearson’s correlation is r = .46. Here are two things to notice:

  1. Each of these variables is a column in a data frame (our data set). We told R where to find the variable by naming the data frame, dat, adding a dollar sign $, and then adding the name of the variable, dat$Read and dat$Schl_climate.
  2. We had to use an argument called use, which is specific to this particular function. We specified use = "complete.obs" because otherwise we’d get an error.8 The reason we’d get an error is because, as we saw with the summary() function, two schools in our data set did not have Schl_climate scores and one school did not have a Read percentage score. We can see other arguments that can be used with the cor() function using the help system, ?cor or using args(cor). Let’s use the latter:
args(cor)
## function (x, y = NULL, use = "everything", method = c("pearson", 
##     "kendall", "spearman")) 
## NULL

There are four arguments. The first two are the data, the second of which is optional if our first one is an object that includes multiple variables, which we will use in a minute9. The third is the use = argument, with its default set to everything, which we overwrote with our use = "complete.obs". The last argument is for the correlation method. The default is Pearson. If we wanted to use Spearman correlation instead of Pearson, we would add this: method = "spearman".

cor(dat$Read, dat$Schl_climate,
    use = "complete.obs",
    method = "spearman")
## [1] 0.4152396

Let’s try another variable with school climate. How about math proficiency? First, let me check the spelling of my math variable using then names() function.10

names(dat)
## [1] "Schl_id"            "County"             "Title_I"           
## [4] "Sci"                "Math"               "Read"              
## [7] "Litrcy_rate_grade3" "Chrn_absntsm"       "Schl_climate"

It is spelled as Math11, so I’ll use dat$Math in the cor() function:

cor(dat$Math, dat$Schl_climate,
    use = "complete.obs")
## [1] 0.4715012

Both reading and math seem to correlate with school climate in the same direction and at very similar magnitudes.

2.1.1 Estimating correlation as a statistic

Sometimes, we wish to estimate correlation as an inferential statistic. For this, we can use the cor.test() function from Base R:

cor.test(dat$Read, dat$Schl_climate)
## 
##  Pearson's product-moment correlation
## 
## data:  dat$Read and dat$Schl_climate
## t = 6.7055, df = 164, p-value = 3.089e-10
## alternative hypothesis: true correlation is not equal to 0
## 95 percent confidence interval:
##  0.3352332 0.5755247
## sample estimates:
##       cor 
## 0.4638681

This gave us the 95% confidence interval, the p-value, and the correlation. We don’t usually estimate correlations as inferential statistics in measurement, but this code is here if we need it.

2.1.2 Creating a correlation matrix

With Base R’s cor() function and the $ indexing, we can only use two variables. If we tried to correlate four variables, we would get an error:

cor(dat$Read, dat$Math, dat$Sci, dat$Schl_climate, use = "complete.obs")

This code will not work because the cor() function expects only the first two arguments to include the data. Here, there are two more arguments that were unexpected. What we can do, instead, is use bracket [ , ] indexing to assign those variables to an object and then perform the cor() function on them. This will return a correlation matrix:

myvarbs <- c("Read", "Math", "Sci", "Schl_climate")
cor(dat[, myvarbs], use = "complete.obs")
##                   Read      Math       Sci Schl_climate
## Read         1.0000000 0.9442737 0.7950828    0.4754034
## Math         0.9442737 1.0000000 0.7619727    0.4814484
## Sci          0.7950828 0.7619727 1.0000000    0.4289676
## Schl_climate 0.4754034 0.4814484 0.4289676    1.0000000

We can assign these results to an object and round them to 2 decimal places:

my_cor_matrix <- cor(dat[, myvarbs], use = "complete.obs")
my_cor_matrix_rounded <- round(my_cor_matrix, 2)
my_cor_matrix_rounded
##              Read Math  Sci Schl_climate
## Read         1.00 0.94 0.80         0.48
## Math         0.94 1.00 0.76         0.48
## Sci          0.80 0.76 1.00         0.43
## Schl_climate 0.48 0.48 0.43         1.00

We can save this object to a CSV file in our working directory (which we can then view in a spreadsheet program such as Excel).

write.csv(my_cor_matrix, "MyCors.csv")

2.2 Variance

The var() function calculates the variance of a variable. Let’s look at the variance of the Read variable. Try the following code. Does it yield a result that you expect?

var(dat$Read)
## [1] NA

Hm. Remember that one of the observations had missing data on the Read variable. We can look at the help menu for this function using ?var or see if we can find something about the arguments using args(var):

args(var)
## function (x, y = NULL, na.rm = FALSE, use) 
## NULL

There is an argument for how to handle missing data, and its default is na.rm = FALSE to not remove missing observations. In other words, if want to estimate the variance of this variable with only the data available, after removing the NAs, we need to set that argument to true:

var(dat$Read, na.rm = TRUE)
## [1] 240.4846

This argument is ubiquitous in R coding. If you have missing data, you will probably need to include that argument in other functions.12 For example, compare these two results:

mean(dat$Read)
## [1] NA
mean(dat$Read, na.rm = TRUE)
## [1] 54.64072

To get the standard deviation, we can either use sd() or sqrt(var()):

vars_read <- var(dat$Read, na.rm = TRUE)
sqrt(vars_read)
## [1] 15.50757
sd(dat$Read, na.rm = TRUE)
## [1] 15.50757

Note that var() and sd() use the n-1 denominator. We address the n as denominator below.

2.3 Covariance

Covariance is just like variance but with two variables instead of one.1314 The cov() function has the same arguments as the cor() function:

cov(dat$Read, dat$Schl_climate, use = "complete.obs")
## [1] 51.61468

2.3.1 Creating a variance-covariance matrix

A variance-covariance matrix15 includes the variance and covariances of all possible combinations of variables. Let’s use the same variables we played with in the correlation matrix.16 The code is nearly identical to what we used with the cor() function—we just replace cor with cov:

my_cov_matrix <- cov(dat[, myvarbs], use = "complete.obs")
my_cov_matrix
##                   Read      Math       Sci Schl_climate
## Read         234.82295 228.84069 215.75695     52.13387
## Math         228.84069 250.10951 213.39620     54.48817
## Sci          215.75695 213.39620 313.59152     54.36183
## Schl_climate  52.13387  54.48817  54.36183     51.21237

The variances are on the diagonal. For example, the variance of Read is 234.82, the variance of Math is 250.11, and so forth. The covariances are on the off-diagonal. For example, the covariance of Read and Math is 228.84 and occurs twice, once below and once above the diagonal.17 Note that these estimates are different from individual variance and covariance estimates, such as from our earlier calculation of var(Read):

var(dat$Read, na.rm = TRUE)
## [1] 240.4846

The reason for this discrepancy is that our covariance matrix included case-wise deletion—that is, any school with a missing score on any of the four variables was eliminated, whereas our variance estimate of the single variable only removed schools missing a score on that particular variable.

The cov(Read, Schl_climate) is in the upper right and lower left cell (52.13) and is also slightly different than if we had calculated covariance using only the two variables (51.61), again because of case-wise deletion.

This is real-world stuff. Most text-book examples of variance and covariance include complete data sets, with no missing data. In those situations, there would be no differences in the estimates because the same observations would be included in both.18

2.3.2 Using the n denominator

The var() and cov() functions use \(n - 1\) as the denominator, so they treat variance and covariance as being of a sample rather than of a complete population. Usually in measurement, for understanding reliability, we use \(n\) as the denominator. We sometimes have to adjust this (such as when we’re digging into reliability), so let’s calculate the number of observations.

With variance, we’re only dealing with a single variable, so we can use the sum() and is.na() functions to get the number of missing variables. To get the number of non-missing variables, we can use a special operator ! which means something like not. The following code with !is.na() will calculate the number of observations that are not missing in the Read variable and assign this number to the n object:

n <- sum(!is.na(dat$Read))
n
## [1] 167

To correct the denominator to be n so the equation is \(var(x)=\frac{\Sigma(x - \bar{x})^2}{n}\) instead of \(=\frac{\Sigma(x - \bar{x})^2}{n-1}\), we multiply the sample variance by \(\frac{n-1}{n}\):

varp_read <- var(dat$Read, na.rm = TRUE)*(n-1)/n
varp_read
## [1] 239.0446

This n as the denominator is what we tend to use in measurement when we’re examining test quality and item functioning.19

If we want the standard deviation, we then take the square root:

sdp_read <- sqrt(varp_read)
sdp_read
## [1] 15.46107

Similarly, with covariance we use n as the denominator, so instead of \(\frac{\Sigma(x - \bar{x})(y - \bar{y})}{n-1}\), we use \(cov(x,y) = \frac{\Sigma(x - \bar{x})(y - \bar{y})}{n}\). I know that there are 166 cases used in cov(Read,Schl_climate), so we can adjust this by \(\frac{166-1}{166}\).

covs_read <- cov(dat$Read, dat$Schl_climate, use = "complete.obs")
covp_read <- covs_read*(166-1)/166
covp_read
## [1] 51.30375

With a variance-covariance matrix, we have to know n for each variance and covariance. When we use “complete.obs”, this n is the same for all cells in the matrix.20 Before, we used sum(!is.na( )) to count the number of cases with a particular column. To get the number of cases across a set of columns, we can use the complete.cases() function along with the sum() function:

n_cov <- sum(complete.cases(dat[,myvarbs]))
n_cov
## [1] 156

We can use that n in our correction of the variance-covariance matrix:

my_cov_matrix_p <- my_cov_matrix*(n_cov-1)/n_cov
my_cov_matrix_p
##                   Read      Math       Sci Schl_climate
## Read         233.31768 227.37377 214.37389     51.79968
## Math         227.37377 248.50625 212.02827     54.13889
## Sci          214.37389 212.02827 311.58132     54.01335
## Schl_climate  51.79968  54.13889  54.01335     50.88408

These numbers21 are all slightly smaller than their counterparts in the sample (n - 1) covariance matrix,

my_cov_matrix
##                   Read      Math       Sci Schl_climate
## Read         234.82295 228.84069 215.75695     52.13387
## Math         228.84069 250.10951 213.39620     54.48817
## Sci          215.75695 213.39620 313.59152     54.36183
## Schl_climate  52.13387  54.48817  54.36183     51.21237

2.3.3 Extra understanding, for use in classical test theory

If our variables were sub-tests or items that we combined into a composite score, we could sum the all the values from the variance-covariance matrix and obtain the same value as we would from calculating the variance of the composite test score. Let’s take a weird example where we might sum three variables, Read, Math, and Sci to get a composite school academic score.22 Here, any school with a missing score on any of these three variables will be removed from the data set.

myvarbs2 <- c("Read", "Math", "Sci")
compos_scor <- apply(dat[myvarbs2], 1, sum)
n <- sum(!is.na(compos_scor))
n 
## [1] 156

This n (156) is the number of schools with data on all three variables, which we got from sum(!is.na(compos_scor)). We could have also used sum(complete.cases(dat[,myvarbs2])) as explained above. Next, with the cov() function, we can adjust the denominator with \(\frac{n-1}{n}\):

covars_RMS <- cov(dat[,myvarbs2], use = "complete.obs")*(n-1)/n 
covars_RMS      # The var-cov matrix
##          Read     Math      Sci
## Read 233.3177 227.3738 214.3739
## Math 227.3738 248.5062 212.0283
## Sci  214.3739 212.0283 311.5813

The sum of all the values in the variance-covariance matrix is this:

sum(covars_RMS) 
## [1] 2100.957

The variance of the composite score is this:

var(compos_scor, na.rm = TRUE)*(n-1)/n 
## [1] 2100.957

So, we have obtained the same value for variance with the two different methods.23 This demonstrates that the variance of the total score, in this case a composite score from three variables, is the same as the sum of all the components in a variance-covariance matrix of those variables used to calculate the score: \(\sigma^2_{(Read + Math + Sci)} = \sigma^2_{Read} + \sigma^2_{Math} + \sigma^2_{Sci} + 2\sigma_{(Read,Math)} + 2\sigma_{(Read,Sci)} + 2\sigma_{(Math,Sci)}\).24

More generally, for a total test score made up of three sub-tests, \(X_1\), \(X_2\), and \(X_3\), \(\sigma^2_{(X_1 + X_2 + X_3)} = \sigma^2_{X_1} + \sigma^2_{X_2} + \sigma^2_{X_3} + 2\sigma_{(X_1,X_2)} + 2\sigma_{(X_1,X_3)} + 2\sigma_{(X_2,X_3)}\). Thinking about the variability in this way will help us when we learn about classical-test-theory reliability.25

Even more generally, for a test score \(Y\) made from a total of \(k\) items (items essentially being little sub-tests), \[\sigma^2_Y = \sum^{k}_{i=1}\sigma^2_{X_i} + \sum^{j=k}_{i<j}2\sigma_{(X_i,X_j)}\]In other words, the total variance of a composite is the sum of all variances and possible combinations of covariances. In this equation, \(i\) and \(j\) are both indexes of \(X\), and \(k\) is the total number of sub-tests. We are using two indexes because we need to distinguish one \(X\) from the next, with one (\(X_i\)) always being earlier in the list of variables than the other (\(X_j\)). For instance, with three sub-tests, \(X_1\), \(X_2\), and \(X_3\), the summed covariances are \(2\sigma_{(X_1,X_2)} + 2\sigma_{(X_1,X_3)} + 2\sigma_{(X_2,X_3)}\), with the \(i\) index respectively referring to \(X_1\), \(X_1\), and \(X_2\) in that operation and the \(j\) index referring to \(X_2\), \(X_3\), and \(X_3\). Notice that in the covariance summation \(X_j\) goes all the way up to \(k\), which is 3 in this case, and \(i\) is always lower than \(j\) (again, to distinguish the variables from each other).↩︎
